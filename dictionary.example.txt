# PLANTILLA del diccionario de WhisperFlow.
#
# ESTE archivo (dictionary.example.txt) se versiona y sirve de punto de partida.
# El que la app lee de verdad es "dictionary.txt", que NO se versiona (está en
# .gitignore) justamente porque suele terminar lleno de nombres de clientes,
# proyectos y jerga tuya que no tienen por qué acabar en un repo público.
#
# Los instaladores (setup.ps1 / install.sh) crean "dictionary.txt" copiando este
# archivo la primera vez. Si estás a mano:
#
#     Windows:     copy dictionary.example.txt dictionary.txt
#     Mac / Linux: cp dictionary.example.txt dictionary.txt
#
# Si "dictionary.txt" no existe, la app lee esta plantilla, así que un clon recién
# bajado funciona igual — solo que sin tu vocabulario.
#
# Hay dos formas de agregar términos:
#
# 1) Un término por línea, escrito EXACTAMENTE como quieres que aparezca
#    (mayúsculas/minúsculas incluidas). Puede ser una frase de varias palabras
#    (ej. "Wispr Flow"). Whisper lo tendrá en cuenta al transcribir, y si lo
#    escribe casi bien pero no perfecto, se corrige automáticamente.
#
# 2) Si notas que Whisper SIEMPRE transcribe mal un término de la misma forma
#    (ej. siempre pone "clod" en vez de "Claude"), agrega una línea con "=>":
#      texto_mal_transcrito => Texto Correcto
#    Ese reemplazo es exacto (no depende de similitud), así que es la forma
#    más confiable para corregir errores recurrentes y específicos.
#
# Las líneas que empiezan con # se ignoran. El archivo se relee en cada dictado:
# agrega o quita términos y pruébalos de inmediato, sin reiniciar la app.
#
# Un detalle que conviene saber: como pista previa al modelo solo caben ~800
# caracteres (Whisper reserva ~224 tokens para eso), así que con más de ~60
# términos los últimos ya no llegan como pista. No quedan inservibles — la
# corrección difusa posterior se aplica a todos — pero poné primero los que más
# te importa que acierte de una.
#
